# Jaam's Weaponry: Extended

Jaam's Weaponry: Extended serves as an official expansion framework for Jaam's Weaponry, allowing you to easily create custom weapons and weapon tiers using simple config files. By automatically generating complete weapon sets and giving you full control over properties, crafting recipes, tooltips, tags, and combat mechanics, it gives you all the tools needed to completely customize your modpack's gear progression.

## Content

- **Custom Tiers & Weapons** — Config-driven framework to define custom material tiers, auto-generate full weapon sets, and build standalone unique weapons with customized properties, recipes, tooltips, tags, and mechanics

## Requirements

- Minecraft 1.20.1
- Forge 47.x
- Jaam's Weaponry
- Java 17
